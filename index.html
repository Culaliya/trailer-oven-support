影片烤箱 TRAILER OVEN

支援

適用 iOS 17、iPadOS 17 與 macOS 14 以上。影片烤箱 1.0 操作說明。

支援 隱私權

一般操作

  1. iPhone 與 iPad 從「照片」相簿選影片或照片。Mac 從「照片」或「檔案」選取。
  2. 選擇預告片、MV 或一鏡到底。
  3. 選一首內建音樂。
  4. 開始烤，接著剪輯，然後輸出。
  5. 存回「照片」。在 Mac 也可以存成檔案。

排錯

  • 素材若還在 iCloud，請先下載到這台裝置，再開始烤。
  • 4K 輸出需要足夠的儲存空間，花費的時間會依硬體而不同。
  • 自動字幕只在這台裝置支援繁體中文或英文的裝置端辨識時可用；否則可以匯入 SRT 或 VTT。
  • 隱私掃描可能漏判。發布前請自行核對畫面、聲音與字幕。

回報問題

公開問題請到 GitHub Issues。請不要附上私人影片、照片、聲音或其他個人資料。
